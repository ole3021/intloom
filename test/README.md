# Tests

- `engineering/`: checks for the workspace and retained release tooling.
- `e2e/npm/`: independent framework and Loom archive installation, public declarations, deterministic example behavior, Kernel data consumption, and actual Code Runs in intloom/workspace scopes.
- `integration/`: reserved for cross-module behavior as it is implemented.

Package-owned tests live next to their implementation. See [development and verification](../docs/maintainers/development.md) for commands and coverage boundaries.
