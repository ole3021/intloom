# IntLoom Studio 0.4.0

- Install Looms from npm, GitHub Releases or local archives and run them from the desktop.
- Track runs, answer questions, review deliveries and export files. Studio and the CLI share the same local service and run history.
- Check for updates in About Studio, read the release notes and choose when to restart.
- Download installers from GitHub Releases. The macOS installer is distributed without Developer ID signing or Apple notarization.
