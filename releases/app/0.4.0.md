# IntLoom Studio 0.4.0

- Stable builds check for Studio updates on startup. Review new versions in the sidebar or check manually in About Studio, then download and choose when to restart.

- Explore the run center and Loom library in a desktop preview. Start a sample run, review its outline, answer requests from child runs and confirm a candidate delivery.
- Open an editable copy or export the saved version using native file operations. History and pending reviews persist across restarts.
- Runs, model calls and service responses use local sample data. Desktop packaging targets macOS, Windows and Linux.
