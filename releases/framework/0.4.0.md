# IntLoom framework 0.4.0

- Distribute Code, Agent and Workflow commands in an npm Loom. Declare commands, inputs, outputs, model requirements and child Looms in `loom.yaml`. Implement each entry with the SDK and build the archive with `intloom-build`.
- Embed the Kernel independently. The host selects the Agent harness. The Kernel tracks child runs, interactions, execution events and immutable deliveries. Hosts can query progress and model usage and retrieve the exact file accepted by the Kernel.
- Callers can request final delivery review. Approval delivers the frozen candidate. A rejected delivery retains its candidate and reason for a separate revision command.
- **Migrating authors and hosts.** The author and runtime contracts have changed since 0.1.0. Put npm identity in `package.json`, point each public command at its entry in `loom.yaml`, and build before distribution. Existing compiled-artifact projects can use `compileLoom` and `packLoom`. Public framework packages support Node `^22.22.0 || ^24.0.0 || ^26.0.0`.
