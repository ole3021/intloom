# IntLoom Framework 0.4.0

- Package Code, Agent and Workflow commands together as a Loom. The Kernel runs declared child Looms and preserves their progress and deliveries.
- Embed the Kernel in your own application. Hosts can answer pending questions, review a delivery and retrieve the exact file that was approved.
- When migrating from 0.1.0, put the package name and version in `package.json`, declare command entries in `loom.yaml`, and build with `intloom-build`.
