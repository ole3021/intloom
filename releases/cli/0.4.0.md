# IntLoom CLI 0.4.0

- Install Looms from npm or a local archive, then run them in a project or through the shared local service.
- Use `status <runId> --watch` to follow a run, answer questions and review delivered files.
- When updating scripts, use `--plain` for machine-readable output and `run stop` to cancel a run. These replace `--json` and `run cancel`.
