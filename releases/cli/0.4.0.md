# IntLoom CLI 0.4.0

- Install `intloom` or `@intloom/cli` for the same executable. Install an npm Loom globally or in a project, inspect its commands and start a run with JSON input. A project installation takes precedence when running from that project.
- Follow a run with `status <runId> --watch`, answer pending requests, review a delivery and export its file. `status` lists all unfinished runs and the ten most recently finished ones.
- Use `startup` to observe the per-user service and its MCP HTTP endpoint. Leaving the foreground view keeps the service running. `shutdown` previews which runs will be cancelled.
- **Updating scripts.** Use `--plain` for machine-readable output, `run stop` to cancel a run and `status <runId>` for details. These replace `--json`, `run cancel` and the former run detail commands. Scaffold new author projects with `dev init` and build with the project's npm build script.
