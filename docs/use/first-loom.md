# Install a Loom from npm

Install the CLI with `npm install --global intloom`. After the first public release of the official meeting-notes package, use:

```sh
intloom install @intloom/meeting-notes
intloom run @intloom/meeting-notes
```

The second command lists the package commands and inputs. [Configure a model](../reference/configuration.md) and follow the [meeting-notes guide](../../examples/meeting-notes/README.md) to produce and export minutes.
