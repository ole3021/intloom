# M01 browser task application

This native ESM project's first Intent has already produced add/complete/delete behavior. `workspace/` contains its business files; `baseline/intloom/` contains the matching formal Artifact/Record history. `baseline/provenance.json` identifies the completed source Run. Two remaining Intents execute in order: editing and bulk operations, then filters, address navigation, localStorage and TodoMVC presentation. knowledge.md supplies the detailed rules as each feature becomes active.

Run with either e2e:cmd or e2e:mcp and --case m01. Execution verifies Workflow completion; optional suite acceptance may inspect saved references and mirrors. UI automation and product-quality comparison are outside this suite.
