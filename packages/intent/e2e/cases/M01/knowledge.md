# Shared knowledge

## K01 — Environment and persistent constraints
Use Node.js 26.4+ ESM with built-in libraries only. One local user, no service, framework, network, account, deployment or synchronization. Preserve workspace conventions and the package test script. Tasks have independent stable IDs, trimmed nonblank titles and completion flags. Duplicate titles are allowed. Keep data project-relative. Invalid operations must not mutate stored data.

## K02 — Confirmation authority
Confirm only current and previously introduced scope, with later explicit changes taking precedence. Choose reasonable internal filenames, ID format and CLI names. Require focused tests and real verification receipts in both implementation and validation. Partial delivery and stopping with unverified targets are not authorized for this success case. Missing essential decisions are a scenario block. Never invent extra requirements or implement the application as the simulated user.
