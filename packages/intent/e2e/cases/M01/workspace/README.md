# TodoMVC starting workspace

This is an initial native ESM browser shell. The Todo application has not been implemented. Keep index.html as the browser entry, put browser modules under src and retain built-in Node development checks under test.

Use Node.js 26.4.0+ to run npm test. The initial check verifies the shell's module wiring; implementation should add focused tests for the actual modules. The application needs no backend, framework, third-party business dependency or compilation step.
