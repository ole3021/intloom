## K20 — Second round changes
The new list default is active tasks. Explicit all, active and completed filters preserve underlying creation order and never mutate stored data. Reject unknown filters. Remove the reopen public operation: invoking its previous command must no longer change a task, and help/documentation must not advertise it. Retire the corresponding requirement while retaining historical Records. Removal completion belongs to this round's completion criteria. Existing completed tasks and persisted IDs must remain intact. Keep add and complete behavior. This round explicitly supersedes K10's list default and reopen support; other prior scope remains active. Module edits needed for these features are allowed; broad restructuring is outside the request.
