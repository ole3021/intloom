# Common questions

**Do I need a model account?** A pure Code Loom can run without model credentials. For an Agent, the operator supplies a compatible model and credentials.

**Does asking a question require a Workflow?** An Agent with a suitable tool-capable model slot can ask for missing information. Choose a Workflow when the business requires explicit stages.

**Can my coding agent approve the final file?** It can help develop the package and answer eligible clarifications. Formal delivery review uses a human response channel. [Questions and review](../use/review)

**What should I share?** Give the recipient a built archive, sample input, expected output and runtime requirements. [Verify the archive](../develop/distribution)
