# From package to delivery

One package can be installed by several people. Each supplies their own input. Each run receives its own ID and result.

| What you have | What it lets you do |
| --- | --- |
| Author source with `loom.yaml` | Change a public command, then rebuild. |
| An npm Loom archive | Install a specific version in your project or globally. |
| A run ID | Query progress, answer a request or find the resulting files. |
| An artifact ID | Retrieve a particular saved version of a file. |
