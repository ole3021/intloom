# Install a Loom from npm

Install the [CLI](./setup). After the first public release, install the official meeting-notes Loom by name and inspect its commands:

```sh
intloom install @intloom/meeting-notes
intloom run @intloom/meeting-notes
```

To produce Markdown minutes, [configure a model with structured output](../reference/configuration) and [run the meeting-notes guide](../use/meeting-notes) with your own transcript.
