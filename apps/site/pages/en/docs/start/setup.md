# Install the CLI

Install the latest stable CLI from npm and print its installed version.

```sh
npm install --global intloom
intloom --version
```

Use a Node.js version supported by the [CLI package](https://www.npmjs.com/package/intloom). If you have a local candidate instead, follow the installation instructions in its README and keep that terminal open.
