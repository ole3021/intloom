# What can I do with IntLoom?

A colleague can package how they make a briefing as a Loom. You supply your brief and materials; a presentation Loom can return editable slides. Each run has an ID, so you can answer a question later or retrieve the exact file delivered.

| Your task | Start here |
| --- | --- |
| Try an existing Loom | [Install a small report writer and get your first file](./start/run). It runs locally without a model key. |
| Summarize a meeting | [Run the official meeting-notes Loom](./use/meeting-notes) on pasted notes or a local transcript. |
| Turn a task into a package | [Make a greeting Loom and try it from a separate project](./start/build). Then [choose Code, Agent or Workflow](./develop/choose-an-entry). |
| Ask a coding agent to build it | [Give it the 0.4.0 authoring guide](./ai/loom-authoring) together with an example input and the result you expect. |
| Look up a command | [Everyday CLI](./use/runs) · [Author CLI](./develop/cli) · [Command reference](./reference/cli) |
