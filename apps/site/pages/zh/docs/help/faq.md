# 常见问题

**必须有模型账号吗？** 纯 Code 类型的 Loom 可以不使用模型。使用 Agent 时，由宿主配置兼容的模型和凭据。

**任务需要提问，一定要写 Workflow 吗？** 能使用工具的 Agent 可以直接补问信息。业务确实要求固定阶段时，再选择 Workflow。

**我的编程 Agent 能批准最终交付吗？** 它可以开发能力包、回答策略允许的澄清问题。正式交付确认需要人工通道。[回答问题和确认交付](../use/review)

**交给其他人时要提供什么？** 已构建归档、示例输入、预期结果和运行要求。[分发前验证](../develop/distribution)
