# 从 npm 安装 Loom

先[安装 CLI](./setup)，再用下面两条命令从 npm 安装 [@intloom/meeting-notes](https://www.npmjs.com/package/@intloom/meeting-notes) 并查看 `summarize` 的用法。

```sh
intloom install @intloom/meeting-notes
intloom run @intloom/meeting-notes
```

要生成 Markdown 纪要，请先[配置支持结构化输出的模型](../reference/configuration)，再按[会议纪要使用指南](../use/meeting-notes)提供自己的会议原文。
