# 让编程 Agent 开发 Loom

把<a href="/downloads/0.4.0/loom-authoring.md" download>《IntLoom 0.4.0 作者指南》原始 Markdown</a>交给编程 Agent。文件包含完整的三个项目源文件、范式选择表、构建与安装顺序，以及检查导出文件正文的方法。Agent 无法访问网址时，可以直接附上下载的文件。

## 给 Agent 一条具体的开发任务

> 按附件中的 IntLoom 0.4.0 作者指南做一个 Loom，将输入文字保存为 report.txt。示例输入是 `{"message":"First delivery"}`。验收时导出的 UTF-8 文件应包含这段文字和结尾的换行。请说明选择入口的理由，交回源码、可安装的归档、调用示例和在独立消费目录中的验证结果。

把任务、输入和验收方法替换成自己的业务需求。需要阶段审批时，说明由谁决定、拒绝后怎么办。需要模型时，说明环境能提供的模型能力，凭据交给宿主配置。若想让外部 Agent **使用已经装好的 Loom**，请读 [MCP 客户端接入](../use/mcp)。
