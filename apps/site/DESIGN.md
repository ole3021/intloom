# 网站设计与交互指南

状态：2026-09-14 已确认并实现组合首页。用户选定 D 的 KV 与第一、第二部分，模块 3 采用方案一（点击切换的层叠产物），模块 4 展示项目进度、后续功能并以 A 式编织动画呼应首屏。早期四版预览及比较入口已移除，当前仅保留此首页。本文区分当前实现与后续可选工具。

## 定位与内容边界

intloom 连接用户意图、需求澄清、方案设计和实现验证。优先解释目标与依据如何跨阶段延续。当前项目处于初始化阶段，未发布正式可安装版本；首页中的任务、需求、设计和检查均为本地固定的流程示例，不连接 AI、仓库或真实执行服务。

- 主张围绕清晰目标、阶段衔接和验证依据。
- 主入口使用了解项目、查看文档、查看源码。正式版本可用前不提供假安装命令、假登录或假在线生成。
- 不虚构客户、用户数、性能收益、运行记录或发布状态。
- 正文优先中文；英文用于品牌辅助语与短标签，不能承载中文页面唯一的必要说明。
- 文档中的技术细节面向维护者；官网的用户流程不展示实现框架或着色器参数。

## 工具选择与使用方式

采用最小满足当前体验的工具；先定义用户需要理解或完成什么，再决定组件与动画技术。安装依赖前核对本地版本、官方文档与静态构建兼容性。以下“按需”工具不是默认安装清单。

| 用途 | 默认选择 | 使用方式与边界 |
| --- | --- | --- |
| 官网与文档框架 | 现有 Rspress 2 + React | 保留静态构建和文档路由；品牌首页用自定义组件。不要为了视觉风格迁移框架。 |

| 标签页、菜单、对话框 | Radix Primitives，按需 | 需要完整复合控件时复用键盘、焦点与 ARIA 行为；先检查是否已有依赖。本次简单按钮选择和原生 details 无需组件库。 |

| 长段滚动叙事 | CSS sticky + IntersectionObserver；复杂同步才用 GSAP ScrollTrigger | 移动端改为正常顺序阅读。GSAP 与 Motion 不同时控制同一个属性，不劫持滚轮。 |
| 流程图、编织、连接线、蓝图 | SVG | 图形用 viewBox；必要文字放在可重排的 HTML 中，避免缩放后不可读。装饰图 aria-hidden，解释图提供标题。固定示例不引入流程图编辑器。 |
| 密集动态线条 | Canvas 2D | 限定像素比；用 ResizeObserver 响应尺寸，用 requestAnimationFrame 绘制；暂停、离屏和隐藏页停止持续绘制，清理监听与观察器。保留 HTML 文案和静态帧。 |
| 真实空间材质、透镜折射 | Three.js，另行选定后使用 | 独立懒加载，准备静态替代和移动端预算。当前首屏是 Canvas 2D 聚合场，不声称真实 3D 折射。 |
| 概念对比 | 会话草图用于快速讨论；仓库内路由用于实际预览 | 最终按浏览器中的真实布局和交互确认，不能用一张静态图片代替交互验收。 |

## 交互与动画原则

1. 标题、正文和 CTA 首次渲染即可阅读；动画不能挡住入口。
2. 微反馈建议 120–200ms；面板切换 250–450ms。具体以真实体验调整，不把时长视为不可变规范。
3. 底部编织 KV 播放一次；首屏连续聚合场景提供暂停。遵循 `prefers-reduced-motion`，减少动画时展示静态构图。
4. 阶段演示使用固定示例；点击选择阶段，内容和选中状态同步。支持键盘、触屏和可见焦点，不能依赖 hover 才能理解。
5. 移动端重排为纵向，禁止为了桌面效果制造整页横向溢出；代码等真正需要横向阅读的局部内容可以独立滚动。
6. 避免动画中频繁触发布局；Canvas 不进入 React 每帧状态更新，组件卸载时必须清理。
7. 外链和文档入口可真实访问；未实现的产品能力只能作为标注清楚的概念示例。
8. 默认使用系统字体，不依赖外部字体请求；主要正文 16px 起、常用控件 14px 起。

## 当前 KV 与内容主题

首屏采用「意图聚合」：从开放想法到明确方向，主标题为“让想法，逐渐有形。”。配色为近黑 #090B12、冰蓝 #A8C8FF 与淡紫 #B7ABFF，使用居中大字和宽幅 Canvas 2D 动态聚合场。支持想法、澄清、成形三阶段选择、暂停与轻微指针响应。

底部使用 SVG 编织线呼应首屏，表达明确方向逐步形成构建。开发流程采用可切换的三层产物构图，保持前景内容正面可读。

设计来源为早期 D 的首屏与核心理念、C 的阶段说明、B 的层叠构图及 A 的编织形态。此处仅记录设计依据，不再保留独立候选页面。

## 已确认的四模块首页

1. **首屏**：D 的聚合 Canvas KV、标题和说明；保留想法/澄清/成形切换、暂停和轻微指针响应。主入口跳到开发流程，另一入口通向文档。
2. **核心理念**：保留 D 第二部分的标题及三项理念，统一深色与冰蓝视觉。
3. **开发流程**：方案一，C 的输入/产出/依据内容结合 B 的层叠构图。左侧选择需求、方案、实现与验证；右侧对应产物移到前景。前景正面阅读，背景两层表现透视；用同一个任务清单示例串联需求摘要、职责图、JavaScript 片段与待执行检查。图片效果采用 HTML/CSS，代码片段只表示保存步骤，不是完整产品或 SDK。
4. **进度**：已具备、正在完善、下一步、后续探索四组事项；不使用百分比或承诺日期。内容在 `components/home/content.ts` 手动维护并记录核验日期，未来功能明确区别于已实现能力。底部复用 A 的编织形态，主线进入视口后播放一次、离屏暂停，减少动画时直接显示静态终态。

首页未增加运行时依赖，采用现有 React、CSS Modules、SVG、Canvas 与浏览器观察器。模块 3 用单个选中阶段联动文案及图层，产物通过阶段 ID 显式映射，背景内容从无障碍树隐藏且不包含可操作控件。移动端先呈现阶段选择与产物，再展示详细说明。首页组件与样式维护在 `components/home/`，独立 KV 维护在 `components/key-visuals/`。

## 文件组织与预览

- `docs/index.mdx`：正式首页路由，使用 blank 页面布局。
- `components/home/Home.tsx`：页面组合、跳转入口与页脚；`home.module.css` 只放首页容器、跳转入口与页脚。`common.module.css` 维护首页共用颜色、基础排版、区块容器、行动链接、品牌文字、焦点与触屏规则，不作为文档全站主题。
- `components/home/ActionLink.tsx`：首屏和进度区共用的行动链接，仅提供 primary/text 外观及外链选项，保留原生链接语义。
- `components/home/navigation/`：导航组件及对应样式。
- `components/home/hero/`：首屏文案、控件、KV 容器布局及对应样式。
- `components/home/principles/`：核心理念及对应样式。
- `components/home/development/`：阶段选择、说明和三种产物展示及对应样式；产物保留在同一模块，不引入通用面板框架。
- `components/home/progress/`：项目进度、KV 容器尺寸与进入视口的播放触发。
- `components/key-visuals/convergence/`：聚合 KV；组件主动引入自身样式，绘制模块负责 Canvas 和浏览器监听。
- `components/key-visuals/weave/`：编织 KV；组件主动引入自身样式，接收 `started` 与 `paused`，自身管理动画、遮罩与减少动画规则。两个 KV 均不依赖首页主题类名或首屏、进度模块的父级类名。
- `components/home/content.ts`：聚合阶段参数与说明、开发阶段内容、手动核验的项目进度。阶段产物以 ID 对应，进度颜色以 `data-status` 状态 ID 对应，调整列表顺序不会改变对应关系。图层深度通过 `data-depth` 表达，不再拼接状态类名。当前层叠视觉仍专为三个阶段设计，增加阶段时需要同步设计图层样式。
- `components/home/links.ts`：首页共用外链、文档地址及导航链接。
- `test/convergence.test.mjs`：使用确定的动画时钟与绘制指令验证暂停、阶段切换、恢复、可见性、减少动画和资源释放。Node.js 24 直接加载仅含可擦除类型的绘制模块，不引入测试依赖。
- `rspress.config.ts`：站点与文档配置，不注册候选设计路由；首页及当前使用的 KV 样式分为独立 `home` 异步包。
- `build/home-styles.ts`：生产构建后在首页 HTML 的 head 内链接哈希样式文件，确保首次绘制即有样式；文件缺失或不唯一时构建失败。
- `test/page-styles.test.mjs`：从首页语义标记读取实际生成的类名，检查样式导出有效、首页预先链接样式，文档与 404 页不直接或通过公共 CSS 引入首页和 KV 规则。

各组件显式导入同目录的 `*.module.css`，通过 `styles` 对象引用局部类名；断点规则放在对应模块中。首页公共样式由 `Home.tsx` 优先引入，子组件只引用需要的共享类名。通用元素规则限制在首页主题范围内，以 `:where()` 降低优先级，让模块规则能够覆盖。不要通过父级选择器访问其他模块的内部类名。CSS Modules 由现有构建器处理，自动隔离类名和关键帧；`components/styles.d.ts` 声明模块导入类型，但不校验具体类名拼写。KV 自身负责绘制与动画规则，页面只决定容器尺寸、位置和何时播放。

聚合动画在挂载时创建绘制器，参数更新只调用 `update`，卸载时调用 `dispose`。暂停、阶段切换与恢复保留动画时间及指针位置；恢复时不累计暂停期间的现实时间。可见性和减少动画设置不能覆盖用户手动暂停。

经常修改的阶段内容与进度保留为数据，具有排版意义的标题及正文继续留在组件中。本次重构未新增运行时依赖，也不将页面改造成通用配置系统。

运行根目录 `bun run dev --filter=@intloom/site`，使用输出的本地地址访问 `/`。开发与生产均只提供当前首页及原有文档。

## 页面样式加载

当前使用 Rspress `builderConfig.splitChunks.cacheGroups` 将 `components/home/` 和当前首页使用的 `components/key-visuals/` 样式提取为同一个首页专用包，减少同一页面的额外请求；框架公共样式继续共享。源码分离与构建分包是两个独立边界。

Rspress 2.0.21 的静态页面生成只预加载路由 JavaScript，不自动链接异步路由 CSS。因此通过 `afterBuild` 为首页补充指向实际哈希 CSS 的 stylesheet 链接，客户端页面切换仍由构建器加载样式。维护时同时检查直接打开首页、文档进入首页、首页返回文档三条路径。访问过首页后，客户端可保留已加载样式；这些规则具有自身作用域，不改变文档外观。

当前产物的框架公共 CSS 约 66.2 KB，首页与 KV 样式约 16.5 KB（均为未压缩文件大小）。文档首次打开只需要公共 CSS。未来在其他页面复用 KV 时，应同步调整样式分组及对应页面的首屏样式链接，避免复用一个 KV 却引入整个首页样式包。

配置依据：[Rspress 构建配置](https://rspress.rs/api/config/config-build)、[Rsbuild 代码分包](https://rsbuild.rs/guide/optimization/code-splitting)；同时核验了本地锁定版本的实现。
