01 / 基准范围与使用规则

一个文件、一种主题、一个品牌。保留设计意图，不复制产品能力或发布规则。

只为 IntLoom

覆盖首页、文档阅读与现有导航。Workflows / Examples 保持现有占位范围；Studio 只展示 planned / coming soon，不在此设计完整产品后台。

一主绿、一副色

主绿同时用于品牌、文字、按钮与成功。副色用于信息、路径、说明。表面、正文和边框的中性色负责层次，不增加第二套绿色或蓝色信息色。

设计与实现分开

本文件是后续视觉设计的参考入口；现站实现仍以样式 Token 和组件为实际行为来源。调整设计时先更新本文件，再同步生产消费者与验证。

网站结构与能力描述继续由现有页面、Guide 和项目状态文档维护。本文件不定义 Workflow 的执行协议，也不把 SOLVE 叙事阶段规定为所有 Workflow 必须拥有的业务阶段。旧配色实验页仅保留历史参考。

02 / 颜色与语义

色值展示从本文件的 CSS Token 读取。主绿唯一；按钮交互不另选品牌绿，也不增加外侧 hover 框。

开启 JavaScript 可查看从 CSS Token 生成的色板；主绿固定为 #14DB49。

用色比例

  • 大面积使用黑色与中性表面，主绿是信号，不作为整页铺底。
  • 每个主要区块只保留一个优先动作；绿色优先落在品牌、关键文字、主按钮与进度。
  • 成功复用主绿；警告用琥珀，错误用红，信息复用副色，不引入蓝色。
  • 状态背景 = 表面 + 10% 状态色；边框 = 表面 + 40% 状态色，均为派生混合，不另选色阶。

边界与对比

  • 普通文字 ≥ 4.5:1；大字 ≥ 3:1。大字按至少 24px 常规字或约 18.7px 粗体判断。
  • 装饰分割线使用 border；必须可辨识的输入控件边界使用 control-border，目标 ≥ 3:1。
  • 主按钮使用柔和深灰字 on-accent，不用纯黑；提示实色标签用 on-status。
  • disabled 只用于真正禁用的控件，不能用低对比冒充正常说明文字。

03 / 字体、字号与文字层次

延续现站字体方向；增加中文系统回退。无需外部字体请求、字体包或新依赖。

Sans / 阅读与标题

Helvetica Neue → Helvetica → Arial → PingFang SC → Microsoft YaHei → sans-serif。用于正文、标题、按钮及中文内容。标题 500，正文 400，动作与强调 600；700 仅用于必要重点。

Mono / 仪表与命令

SFMono-Regular → Consolas → Liberation Mono → PingFang SC → monospace。用于命令、代码、标签、编号与状态。不要把整篇正文改成等宽；中文不会保证等宽宽度。

04 / 网格、间距与形状

沿用现站 1100px / 760px 的响应式分界；这是设计基准建议，不新增断点系统或配置层。

容器与栅格

  • 内容最大宽 1280px，居中。
  • 桌面 12 列；首屏 7 / 5 分栏。
  • 760–1100px 按 8 列规划；减少侧栏和区块内边距。
  • ≤ 760px 按 4 列规划，主要内容改为单列。
  • 页面左右留白：48 / 32 / 20px。

垂直节奏

  • 以 8px 为主节奏，4px 用于精细对齐。
  • 页面大区块 64–96px；窄屏 40–48px。
  • 卡片内边距 24px；窄屏 16–20px。
  • 标题与内容间 16–24px；组件内 8–12px。
  • 导航基础高度 84px / 72px；内容换行时允许增高。

形状与边界

  • 控件圆角 4px，卡片 8px。
  • 胶囊只用于短标签，不把所有元素做成 pill。
  • 边框常规 1px；焦点轮廓 2px，偏移 4px。
  • 图标常规 16–20px；点击区域至少 44 × 44px。
  • 不用大范围发光、重阴影、玻璃层或绿色页面雾化。

首页建议维持现有信息顺序：Hero → 静态关键词带 → Principle → Workflow → CLI → Studio（planned）→ Project status → Closing / Footer。文档由 Rspress 负责导航、目录与搜索，设计文件不重新实现文档框架。

按钮交互 / 三个待选方案

下方三组始终保留各自效果，便于悬停比较。“应用预览”只切换本页其他按钮，尚未确认最终方案。默认预览 A。

A / 表面反馈

主操作轻微压暗至 94%，文字一起派生；次操作填充中性抬升面。不移动，不增加外框，保留控件自身边界。

B / 轻微上浮

主操作和次操作悬停时上浮 2px，颜色不变。不发光，不增加外框；减少动态效果时取消位移。

C / 实色 + 文字

主操作保持实色绿；次操作使用无边框的副色文字。悬停只加文字下划线，更适合简洁的 terminal 风格。

半高 /// 连续进度

整条轨道连续铺满可用宽度，按斜杠约 17px 宽、4px 间距动态计算总数，再均分至各阶段；余数最多相差一个。下方标题跨越对应区域，没有阶段间额外断口。字符高度 14px，完成区域保持主绿、待执行保持中性灰。BUILD 复用原有进度斜块，从左至右依次点亮，末尾重新从左侧开始；任一时刻只有一个执行块亮绿，其余保持灰色。空隙始终留空，不叠加 Logo、不平移图形、不虚构进度增长。

DEMO / 2 of 4 stages · not a live run. 每 256ms 切换至下一个执行块，速度为原 320ms 的 1.25 倍；不交叉渐变，确保不会同时亮起两个块。支持暂停，减少动态效果或打印时保留当前亮块、停止切换。

空状态

先说明没有什么，再给出下一步。示例：“尚无运行记录；创建项目并运行工作流后，可在这里查看。”不把空状态冒充加载或错误。

Logo 与图标

Logo 以现有 IntLoom 三模块结构作示意，绿色模块跟随主色，其他模块跟随正文中性色。本文件不替换现有品牌资产；最终 Logo 比例、动效与导出文件另行确认。

About IntLoom

IntLoom is a local workflow framework for coordinating agents, code, and human decisions.

08 / 动效、可访问性与验收

动效只解释状态，不制造能力假象。以下对比度按本文件实际 Token 和派生背景计算，不是完整网站的无障碍认证。

动效边界

  • 按钮反馈约 160ms，不新增品牌绿；候选 A 的压暗仅为派生交互状态。
  • 执行区每 256ms 依次点亮一个原有斜块，末尾回到首块；不移动图形，不在黑色空隙绘制绿色，不让两个执行块同时亮起。
  • 支持手动暂停；prefers-reduced-motion 或打印时停止切换，保留一个静态亮块；减少动态效果时也取消按钮位移。
  • 不自动轮播、滚屏、持续移动关键词带，扫描不表示真实完成量。

实现验收清单

  • 320、390、760、1024、1440px，无整页横向溢出；代码或表格可局部滚动。
  • 键盘可访问导航、按钮、输入、折叠菜单与 Tab；当前项及焦点明确。
  • 错误不能只用红色；进度不能只用颜色或动画，斜杠数量随可用宽度改变。
  • 中英标题句号同为实心方块；子导航只有一个当前叶子项，父级不同时高亮。
  • 放大到 200% 与系统字号调整后不丢失文字或操作。
  • 上线前覆盖真实首页、Guide、搜索结果、空状态和错误页面；样例通过不代表消费者已同步。

开启 JavaScript 查看实际对比度。
