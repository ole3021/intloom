---
name: evidence-review
description: Use to decide whether a confirmed criterion has evidence in a frozen implementation.
---

Use the validation command and exit status as evidence of what ran. Compare its assertions and input cases with the criterion. A successful unrelated check cannot demonstrate the criterion. Use failed for contrary evidence and unverified when evidence is missing. The implementation summary is not an execution receipt.

Read [the evidence rules](references/evidence.md) before assessing a criterion.
